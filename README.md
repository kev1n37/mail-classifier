Наш проект

Проект сортирует входящие письма по категориям.

На входе есть архив data/raw/inbox.zip.
Скрипт распаковывает его в data/inbox.
После этого программа читает письма, определяет категорию по ключевым словам и копирует файлы в папки внутри data/output.


Структура проекта

mail-classifier

Схема работы проекта

1. inbox.zip
2. распаковка архива
3. data/inbox
4. чтение писем
5. определение категории
6. data/output
7. CSV-отчет и лог обработки


Основные модули

config.py
Хранит пути к папкам и список категорий.

models.py
Содержит ClassificationResult.
В нем сохраняются категория, причина и статус обработки.

reader.py
Читает письма из .txt файлов.
Если файл пустой или формат неподходящий, возникает ошибка.

classifier.py
Определяет категорию письма по ключевым словам.
Например, ошибка 500 и работа остановлена относятся к critical_incident.
Chrome и браузер относятся к software_issue.

processor.py
Связывает все вместе.
Он берет файлы, читает их, классифицирует и копирует в нужные папки.

report.py
Создает CSV-отчет classification_report.csv.

main.py
Запускает обработку, сохраняет отчет и выводит статистику.

run.sh
Очищает старые данные, распаковывает архив и запускает Python-программу.


Категории:

В проекте используются такие категории:
critical_incident
support_escalation
software_issue
hardware_issue
access_onboarding
finance_billing
document_approval
maintenance_info
spam_phishing
meeting_communication
hr_admin
monitoring_alert
unknown
error
(unknown используется тогда, когда письмо не удалось уверенно классифицировать)
(error используется тогда, когда файл невозможно обработать).


Как запустить проект:

Сначала нужно установить зависимости:
python3 -m pip install -r requirements.txt

Потом запустить проект:
bash run.sh

После запуска результат будет в папке:
data/output

CSV-отчет будет здесь:
data/output/classification_report.csv

Лог обработки будет здесь:
logs/processing.log


Как запустить тесты:

Для запуска тестов используется команда:
python3 -m pytest

Тесты проверяют классификацию писем, чтение .txt файлов, пустые файлы и неподдерживаемые форматы.


Кратко про логику:

Программа работает по простому алгоритму.
1. Распаковывает inbox.zip.
2. Читает письма.
3. Ищет ключевые слова.
4. Выбирает категорию.
5. Копирует письмо в нужную папку.
6. Создает CSV-отчет и лог.
